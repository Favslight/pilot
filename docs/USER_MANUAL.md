# User Manual

## Login

1. Open `/login`.
2. Enter an administrator email and password.
3. For demonstration before seeding, use **Continue as Guest**.

## Dashboard

The dashboard shows student totals, staff totals, class distribution, charts, notifications, and recent activity.

## Register Student

1. Go to **Students**.
2. Click **Register Student**.
3. Complete the wizard: Personal, Contact, Guardians, Medical, Documents, Passport, Review.
4. Submit the form.

## Promote Student

1. Go to **Academic Records** or open a student profile.
2. Choose **Promote Student**.
3. Select the destination session, class, arm, status, and remarks.
4. Submit. A new academic record is created; old records are preserved.

## Bulk Promotion

1. Go to **Student Promotion**.
2. Enter source session/class/arm and destination session/class/arm.
3. Select students.
4. Click **Promote Selected Students**.

## Register Staff

1. Go to **Staff**.
2. Click **Register Staff**.
3. Complete Personal, Employment, Passport, and Review steps.
4. Submit the record.

## Search Records

Use the header search box to find students, staff, classes, departments, sessions, and users.

## Generate Reports

1. Go to **Reports**.
2. Choose Student, Staff, or Academic report.
3. Preview the report.
4. Use Print, CSV, or PDF-ready action.

## Export Data

Most tables include an **Export CSV** button. The settings page includes SQL backup export.

## Manage Users

Go to **Administration** to view users, roles, and permissions. Administrators can assign role permissions.

## Configure School Settings

Go to **Settings** to update school details, logo, contact information, leadership, departments, class arms, and backup export.
